# Wall-E PCB 引脚需求

> 基于 `wall-e_xiaozhi`（主控）和 `wall-e_esp32_cam`（CAM 模组）实机调通结果整理。
> 当前 PCB 存在 3 处 GPIO 冲突，新设计需解决。

## 架构


## 二、CAM 模组 ESP32-S3-CAM（OV3660, 8MB PSRAM）

要求：ESP32-S3 带 **8MB Octal PSRAM**（眼屏 framebuffer 需 115KB），
摄像头 OV3660（DVP 接口），板载 Wi-Fi 天线。

|------|---------|-----------|------|
| SCK  | 42 | 42 | 共享 SPI 时钟 |
| MOSI | 45 | 45 | 共享 SPI 数据 |
| DC   | 41 | 41 | 共享 数据/命令 |
| RST  | 46 | 46 | 两屏共享复位 |

## 三、全局约束

### 3.1 Strapping 引脚注意事项

ESP32-S3 以下引脚上电时有特殊功能，PCB 设计需确保外设默认电平不干扰启动：

| GPIO | 启动功能 | 当前用途 | 风险 |
|------|---------|---------|------|
| 0 | 启动模式（低=下载） | 按键 + 眼屏 CS_R | 上电如被拉低进下载模式 |
| 3 | JTAG | 4G 保留 | 低 |
| 45 | VDD_SPI 电压 | 眼屏 MOSI | 上电需高阻/高电平 |
| 46 | ROM 日志 | 眼屏 RST | 已调通，输出模式无碍 |

### 3.2 硬件设计建议

- **眼屏 GC9A01 TE 引脚**接到 CAM 空闲 GPIO，可实现帧同步消除撕裂
- **眼屏 CS** 各接独立引脚，左/右无需对称，空闲 GPIO 任选
- **SD 卡**走独立 SPI 总线（SPI2），MISO/MOSI/CS 选不与摄像头 DVP 冲突的引脚
- **两颗 ESP32-S3 均需 8MB Octal PSRAM**
- **主控 USB D-/D+（GPIO19/20）被占用**，调试口走 UART0 引出排针
- **摄像头 OV3660 DVP 并口** 8 条数据线需等长布线
- **共地**：主控与 CAM 的 UART 需共地
