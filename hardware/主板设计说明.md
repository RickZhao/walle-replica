# Wall-E 新硬件主板设计说明（方案 A：双层堆叠模块插接底板）

> 2026-08-10。配套文档：`hardware/新硬件BOM与尺寸.md`（BOM 与尺寸，尺寸已经人工复核更正）。
> 本文件是方案 A 底板的**原理图级设计输入**：所有连接器逐脚定义 + 电源网络 + 布局建议，可直接照此在 EDA 工具中画原理图/PCB。
> 结构：**单块 PCB、模块双面插接堆叠**——顶层 ESP32-S3 与 LU9685 并排，底层 DC-DC 降压 + TB6612 + PCM5102 + PAM8406；板上只有连接器、分压电阻等少量元件，全部直插，2 层板即可。12V 仅 2 个输入焊盘，开关/保险丝不上板。

---

## 1. 连接器 / 插座定义（逐脚）

### J1 — ESP32-S3 主控插座（2×22P 排母，2.54mm）

两排 22P 沿板子**长边**（57.15mm 边）左右分布：单排首尾针距 **53.34mm**（21×2.54，人工实测），两排间距 **25.40mm**（厂商图纸值，画封装前卡尺复核）。

排针顺序按 `YD-ESP32-S3资料` 尺寸图与实物照片（天线端 → USB 端）。**加粗**为底板实际使用的网络，其余脚位排母照焊但不接线（NC）。

| 左排（天线端→USB端） | 网络 | 右排（天线端→USB端） | 网络 |
|---|---|---|---|
| 3V3 | **3V3** | GND | **GND** |
| 3V3 | 3V3 | TX(43) | **UART0_TX** → J-DBG |
| RST | NC | RX(44) | **UART0_RX** → J-DBG |
| 4 | **MIC_WS** | 1 | **BAT_ADC**（分压中点） |
| 5 | **MIC_SCK** | 2 | **4G_TX**（可选） |
| 6 | **MIC_SD** | 42 | **TFT_BLK** |
| 7 | **DAC_DIN** | 41 | **BTN_RST** |
| 15 | **DAC_BCK** | 40 | **TFT_DC** |
| 16 | **DAC_LCK** | 39 | **BTN_VDN** |
| 17 | **MOT_AIN1** | 38 | **BTN_VUP** |
| 18 | **MOT_AIN2** | 37 | NC |
| 8 | NC | 36 | NC |
| 3 | **4G_RX**（可选） | 35 | NC |
| 46 | NC | 0 | **BTN_BOOT** |
| 9 | **CAM_TX**（主控发） | 45 | **TFT_RES** |
| 10 | **CAM_RX**（主控收） | 48 | NC |
| 11 | **MOT_PWMB** | 47 | **TFT_SDA** |

> ⚠️ 天线区 4.6mm 必须悬空出板边或设禁布区，底板铺铜避让。

### J2 — LU9685 舵机驱动插座（2×7P 排母，2.54mm）

模块左右两排 7P 弯针，丝印相同。两排同网络可并联（增加载流）。

| 模块丝印 | 底板网络 | 说明 |
|---|---|---|
| V+ | **5V_SERVO**（大电流轨） | 两排 V+ 都接，分摊舵机电流 |
| DVCC | **5V** | 逻辑电 |
| SDA | **I2C_SDA** (GPIO20) | |
| SCL | **I2C_SCL** (GPIO21) | |
| RXD | NC | 串口模式不用 |
| TXD | NC | |
| GND | **GND** | |

> 模块上另有 2P 接线柱（V+ 舵机电源入口，厂商标 3.08mm 间距）。**建议降压模块 5V 输出除走底板铜皮到 7P 的 V+ 外，再备一根短线直接进该接线柱**（舵机峰值 4–6A，排针单脚 ~3A）。
> 16 路舵机座在模块本体上，布局时舵机座一侧朝板边，方便插拔延长线。通道 9 = 照明灯（`LIGHT_PWM_CHANNEL`）。
> I2C 地址默认 0x40（丝印 0x80 为 8 位格式），与固件一致，A0–A4 跳线不动。

| AO1/AO2 | → **J-MOTA** | PWMB | **MOT_PWMB** (GPIO11) |
| BO1/BO2 | → **J-MOTB** | BIN1 | **MOT_BIN1** (GPIO12) |
| | | BIN2 | **MOT_BIN2** (GPIO13) |
| | | STBY | **5V**（常开，`MOTOR_STBY_WIRED=0`） |

### J4 — GY-PCM5102 DAC 插座（排母）

| 模块丝印 | 底板网络 |

| VCC/VIN | **5V** |
| GND | GND |

### J5 — PAM8406 功放插座（排针/焊盘）

| 引脚 | 网络 |
|---|---|
| 5V/VDD | **5V** |
| GND | GND |

| L+ L− | → **J-SPK1**（XHB 2P，喇叭 1） |

### J6 — DC-DC 降压模块（10–36V→5V）焊盘/端子

实测 42.00 × 24.00mm，输入 2P 在左侧（间距 18.00mm），输出 2P 在右侧（间距 18.00mm）：

| 引脚 | 网络 |
|---|---|
| IN+ / IN− | **12V**（开关后） / GND |
| OUT+ / OUT− | **5V 总轨** / GND |

> ⚠️ 核实模块额定电流 ≥5A 持续（9× MG90S 联动峰值 4–6A），不够就换 5A/10A 模块，焊盘间距按新模块实测改。

## 2. 板上少量元件

| 位号 | 器件 | 说明 |
|---|---|---|
| D1 | 10A10 二极管（或 P-MOSFET 理想二极管） | 防反接，**可选**——不用则短接焊盘 |
| R1/R2 | 100k + 33k（1%） | 电池分压：**12V 输入焊盘**→ R1 → GPIO1 → R2 → GND；12.6V → 3.13V |
| D2 + R3 | 3mm LED + 1k | 5V 电源指示 |
| C1/C2 | 470µF/25V 电解 + 100nF | 5V 轨入口储能（降压模块近旁） |
| C4G | 470µF/10V 电解 | J-4G 接口旁，4G 发射 2A 瞬态储能（掉压即掉网） |
| R_EN | 10k 上拉电阻 | J-4G 的 EN 脚 → 5V，默认开机（4G 模组电源使能） |

> 以上小元件全部放**底层**（与降压模块同面），不占顶层空间。

## 3. 电源网络与设计规则

| 网络 | 电流 | 走线要求（1oz 铜） |
|---|---|---|
| 12V（输入焊盘→降压 IN / TB6612 VM） | ≤5A | ≥2.5mm，短直 |
| 5V_SERVO（降压 OUT → LU9685 V+） | 峰值 4–6A | **铺铜 ≥4mm** + 模块 2P 端子直连备份线 |
| 5V（逻辑：主控/CAM/DAC/功放） | ≤2A | ≥1.5mm |
| 5V_4G（J-4G → ML307R-DL） | 发射瞬态 2A | ≥1.5mm 独立走线，接口旁 470µF 储能；掉压即掉网 |
| 3V3（主控板载 LDO → MIC/TFT） | ≤0.3A | 普通信号线宽 |
| GND | — | **双面铺铜**，多打过孔；降压、LU9685、TB6612 的 GND 星型汇合到电池入口 |

- 信号线宽 ≥0.25mm（10mil），间距 ≥0.2mm，2 层板 1.6mm 厚，全直插。
- 舵机大电流回路不经过主控 5V 脚；主控由逻辑 5V 供电（接 J1 的 5V 脚，经其板载 LDO 出 3V3）。

## 4. 布局与板框建议

> 📐 **等比例布局示意图：`hardware/主板布局示意图.html`**（浏览器打开，6px=1mm，顶/底两面视图，模块按实测尺寸绘制）。

- **结构：单块 PCB、模块双面插接堆叠**。顶层（朝上）= ESP32-S3 与 LU9685 并排；底层（朝下）= DC-DC 降压 + TB6612 + PCM5102 + PAM8406 + 小元件（C1/D1/R1R2/LED/J-DBG 焊盘）。
- **建议板框：90 × 72mm**，四角 M3 安装孔（Ø3.2，孔边距 ≥4mm）；安装铜柱高度 **≥15mm**（底层模块最高约 11mm）。
- 双面插接可行性：排针+排母总高 ~8.5mm，背面针头露头仅 ~2.4mm，**上下层模块 footprint 允许重叠**（模块背面无高器件即可）。
- 布局原则：
  - **ESP32 水平居中**（USB-C 朝左，前方留 ≥15mm 插线空间）；天线区在模块**右端**、板内设**禁布条**（宽 ≥4.6mm，无铜无件，推荐 ≥6mm）。
  - LU9685 16 路舵机座朝**下板边**出线；其顶部 V+ 2P 端子用短线直连底层降压输出（5V 舵机轨）。
  - 底层：降压与 PAM8406 放上排，PCM5102 与 TB6612 放下排，小元件集中右下；PCM5102 ↔ PAM8406 模拟走线经板层最短连接。
  - 对外连接器全在**顶层左右板边**：**MOT-A（左）↔ MOT-B（右）同高镜像**（与 ESP32 同一水平区）；**左板边** = MOT-A + **J-PANEL（FPC22P → 副板）**；**右板边** = MOT-B + CAM；**顶边** = 12V 输入焊盘居中 + **J-4G（4G 模组）靠左**；下边 = 舵机线出口（不放连接器）；J-DBG 3 焊盘在底层。**面板件（喇叭/麦/按键/1.3″屏）不设单列接口**——全部经 J-PANEL 的 22P 软排线到副板（见 §6）。
  - **4G 模组（远程）**：ML307R-DL **mini 核心板（AT 固件，24.2×20.0）** 经 **8P 双头排母线束 ~30cm** 接 J-4G，核心板放机体空位，吃 5V（自带稳压 + SIM 座）；J-4G 的 5V 独立走线 + 接口旁 470µF（C4G），UART 交叉（模块 TXD→GPIO3、RXD←GPIO2）；**EN 高电平通电 → R_EN 10k 上拉 5V 默认开机**；BAT/DP/DN 不用。
  - **12V 输入仅 2 个焊盘**（Ø2mm，间距 5.08）；开关与保险丝不上板，在板外电池线上自行串接（面板 8mm 带灯开关串 BAT+）。

## 5. 摄像头背板（头部小板）

> 参考实物照片：`hardware/另一套硬件-摄像头背板.png`（第三方背板：两列排母插 CAM 模块 + 顶部两个排线座接眼屏）。
> 布局示意：`主板布局示意图.html` 下方第三视图。CAM 模组与两块眼屏都插在这块板上，经 XHB 4P 50cm 线连主板 J-CAM。

- **板框：40 × 55mm**，M2.5 安装孔 ×4。
- **CAM 模块插座**：2 列排母（2.54），**排距/针序按实际 CAM 模块**（Step 4.5 板型核对后定稿）。第三方背板参考针位（照片读数，以实物为准）：左列 `14 · 21 · 41 · 42 · 45 · 46 · GND · 5V`，右列 `21 · 14 · GND · 5V · U0R · 3V3 · GND · 0 · 2 · 3V3`。
- **眼屏接口 ×2**：按眼屏转接板引出形式（多为 8P FFC 排线座或 2.54 排针，**实物实测后定稿**——BOM 的 22P FPC 已用于主板↔副板，不在此处）。每屏实际使用 7 个信号：

  | 信号 | 左屏 | 右屏 |
  |---|---|---|
  | SCL / SDA(MOSI) / DC / RST | GPIO42 / 45 / 41 / 46（两眼共享） | 同左（共享） |
  | CS（片选，厂商丝印 L/R） | GPIO2 | GPIO0 |
  | VDD / GND | 3V3 / GND | 3V3 / GND |

  **FPC 22P 针序按眼屏转接板实物实测**，未用针悬空；注意 GPIO0/45/46 为 strapping 引脚，上电电平需兼容。
- **J-PWR 4P（XHB）**：来自主板 J-CAM——5V / GND / 主控9→CAM RX(14) / 主控10←CAM TX(21)。**UART 交叉在背板上完成**（主板侧 J-CAM 按 9/10 直出）。
- **J-DBG 焊盘 ×3**：CAM 日志（U0T/U0R/GND），板型核对与联调用。

## 6. 副板（面板板）

> 参考实物照片：`hardware/另一套硬件-副板.png`。面板件（喇叭/麦/按键/1.3″屏）集中在这块板上，经 **FPC 22P 1.0mm 反向 30cm** 连主板 J-PANEL。布局示意见 `主板布局示意图.html`（副板视图）。

- **板框：70 × 35mm**，M2.5 安装孔 ×4，装于机体前面板内侧。
- **J-PANEL 对端座**：FPC 22P 1.0mm 下接翻盖座（BOM #28）×1，接主板 J-PANEL 的 22 针（反向线按丝印对插，网络定义不变）。
- **喇叭**：SPK_L± / SPK_R± 直焊焊盘（2828 腔体喇叭 ×2，PAM8406 差分输出共地）。
- **麦克风**：INMP441 2×3P 接口（VDD=3V3、GND、SD、SCK、WS、L/R→GND；针序以实物丝印为准）。
- **按键 ×4**：CHA PB13 焊盘，各一脚接信号（BOOT/音量+/音量−/重启）、一脚接 GND（GPIO 内部上拉，低有效）。
- **1.3″ 状态屏**：7P 排母（GND/3V3/SCL/SDA/RES/DC/BLK），插 ST7789 模块。
- 22 针逐脚定义见 §1 J-PANEL 表。

## 7. 打样前检查清单

1. 按 `新硬件BOM与尺寸.md` §8 清单逐项复核（CAM 板型、各模块实测尺寸、降压模块电流）。
1b. 摄像头背板专项：CAM 模块排距/针序、眼屏 FPC22P 针序（Step 4.5 阻塞项），均按实物实测后定稿。
2. J1 排母 2×22P：单排首尾 **53.34mm**（21×2.54）、排间距 **25.40mm**、孔径 Ø0.9–1.0mm；LU9685 两排 7P 的排距按实物卡尺（尺寸图 64.01×27.18，排针在短边两侧）。
