## 3. 引脚终稿（以 `config.h` 为准，PCB 网络名建议照此丝印）

| 电机 TB6612               | PWMA=19, AIN1/2=17/18, PWMB=11, BIN1/2=12/13, **STBY 接 5V**（板上上拉，固件不驱动） |

| 4G ML307R-DL（核心板） | ESP32 TX=2 / RX=3（交叉接模块 RXD/TXD）；5V/GND；PWRKEY 模块侧下拉自动开机 |
| 日志 UART0                | GPIO43/44（**USB 串口已禁用**，务必在板上留 43/44/GND 调试焊盘或排针）               |

⚠️ **GPIO19/20 = ESP32-S3 原生 USB D-/D+**，已被 PWMA 和舵机 SDA 占用——板载 USB-C 口只剩供电 + 固件烧录（烧录走 ROM bootloader 的 USB-CDC 仍可用，但应用日志必须看 UART0）。
⚠️ **GPIO0/45/46 是 strapping 引脚**：按键 BOOT=0（正常，按下为低）；眼屏在 CAM 侧占用了 CAM 的 0/45/46——主板侧不引这些脚做他用即可。

## 4. 电源树与电流预算

```
12V 电池 ── 8mm 带灯开关（板外串接）──┬── TB6612 VM（电机，直通 12V）
                           └── DC-DC 降压 → 5V 大电流轨 ──┬── LU9685 V+（舵机动力电，峰值最大）
                                                         ├── LU9685 DVCC（逻辑电）
                                                         ├── ESP32-S3 5V、CAM 5V
                                                         ├── ML307R-DL 4G（J-4G，发射峰值 2A，旁加 470µF）
                                                         ├── PCM5102 VIN、PAM8406 VDD
                                                         └── （板载 LDO → 3.3V：INMP441、ST7789、眼屏）
```

- **舵机电流**：9× MG90S，单只堵转约 650mA，全身联动峰值可达 4–6A → **降压模块务必 ≥5A 持续**，LU9685 V+ 走线/端子按 8–10A 余量设计（原 BOM 的 DC-DC 模块需核实额定电流，Mini360 类小模块不够用）。
- **4G 模组**：ML307R-DL 吃 5V（模块自带稳压 + SIM 座），发射瞬态 2A——J-4G 的 5V 用独立走线（≥1.5mm）+ 接口旁 470µF 储能；若 4G 与舵机联动同时工作，降压建议 ≥6A。
- 电机 12V 与 5V 逻辑**共地**；TB6612 VCC=5V。
- LU9685 板载 AMS1117 由 V+ 生成 DVCC——所以模块的 V+ 和 DVCC 可以都接 5V 轨，也可只接 V+ 让模块自产 DVCC（原引脚表是两路都接 5V）。
- 照明灯：LU9685 通道 9（`LIGHT_PWM_CHANNEL=9`），小功率 LED + 限流电阻可直接插舵机座；大功率灯需在信号脚加 N-MOSFET 低边开关——PCB 可预留一个 MOSFET 焊位。
- 电源入口：开关/保险丝不上板（板外电池线串接，建议 10A 保险丝 + 8mm 带灯开关）；板上仅留 12V 输入焊盘 ×2 + 可选 D1 防反接焊盘。

## 6. LU9685 模块要点（若整块插接使用）

- 默认 I2C 地址丝印 **0x80**（8 位写地址格式）= 7 位 **0x40**，与 PCA9685 默认地址一致，固件无需改；A0–A4 跳线可改地址。
- 对外接口（左右各一排 7P 弯针，2.54）：V+ / DVCC / SDA / SCL / RXD / TXD / GND——**只接 SDA/SCL/DVCC/V+/GND 即可**（固件走 I2C；TXD/RXD 是它的串口协议模式，不用）。
- 模块电源入口是 2P 接线柱（厂商 BOM 标 3.08mm 间距）。
- 厂商资料内部矛盾（已在图上核对）：原理图 U2 标 **AMS1117-5.0**、BOM 图写 "AMS1117-3V3"；E1 原理图 470µF/16V、BOM 图 1000µF/16V。**若方案 B 自绘该电路，以原理图（5.0 / 470µF）为准**——引脚表要求 DVCC=5V。
- 16 路舵机座丝印 PWM/V+/GND，三排排针（黑/黄/红区分 GND/信号/V+）。

## 7. 两种 PCB 方案

- **方案 A — 模块插接底板**（已选定，双层堆叠）：单块 PCB 双面插排母——顶层 ESP32-S3 与 LU9685 并排，底层 DC-DC + TB6612 + PCM5102 + PAM8406；板上仅连接器与少量元件（分压/防反接/指示），开关/保险丝不上板（12V 仅 2 个输入焊盘）。低风险、可替换、2 层板。详细设计输入见《主板设计说明.md》，布局见《主板布局示意图.html》。
- **方案 B — 部分整合**：把 LU9685 电路（LQFP32-7×7 + AMS1117 + 排针）和 TB6612 直接画上主板（原理图/PCB 源文件在 `LU9685-20CU…/PCB文件与BOM清单/20路舵机控制模块PCB.PcbDoc`，Altium 格式可参考），减少插接高度。工作量与风险更高，首版不建议。
